    ¿Qué diferencia hay entre Lite y el APK?

    Lite se instala desde un navegador compatible. El APK es el archivo de instalación de la aplicación para Android.

    ¿Cómo lo instalo en iPhone o Mac?

    Elige la opción para iPhone o Mac, toca Descargar e instalar y sigue los pasos para instalar el perfil de configuración.

    ¿Dónde encuentro el APK descargado?

    Busca el archivo en las descargas de tu navegador o en la carpeta Descargas del administrador de archivos.

    ¿ALGUNA DUDA?

    ¿Qué hago si no aparece Instalar?

    Abre el menú del navegador y busca Instalar aplicación o Agregar a la pantalla principal. Si la opción no aparece, prueba con un navegador compatible con aplicaciones web.

    ¿Lite es un archivo APK?

    No. Lite se instala desde el navegador. Si prefieres el APK para Android, vuelve a la página de descarga.
